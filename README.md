# Data Structure Visualizer

A real-time, interactive data structure and algorithm visualizer built with a decoupled architecture. This project uses **FastAPI** and **WebSockets** for a Python backend engine paired with a responsive **HTML/CSS/JavaScript** frontend.

## 🚀 Features
- **Real-Time Streaming:** Uses WebSockets to stream algorithmic state changes instantly from Python to the browser.
- **Decoupled Architecture:** Clean separation of concerns between computational logic (Python) and visual rendering (Web Components/DOM).
- **Interactive UI:** Smooth control over animations, additions, and deletions using native HTML elements and CSS.
